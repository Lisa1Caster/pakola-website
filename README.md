# 🌸 Pakola Flavoured Milk — Animated Showcase Website

An ultra-smooth, 283-frame sticky canvas scroll-driven animated showcase website for **Pakola Rose & Strawberry Flavoured Milk**.

## ✨ Features
- **Smooth Canvas Scrubbing**: 283 preloaded & decoded frames synced directly with sticky window scroll.
- **Modern Responsive Design**: Built with Tailwind CSS, Material Symbols, and Plus Jakarta Sans typography.
- **Zero Latency Performance**: Full HD (1920x1080) canvas rendering with high-quality scaling and automatic frame caching.
- **Interactive Showcase**: Nutrition facts, product specs, interactive packs, and customer testimonials.

## 🚀 How to Run Locally
Open `index.html` directly in your browser, or run a local server:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then visit `http://localhost:8080`.

## 🌐 Live Deployment
This website is ready for 1-click deployment on **GitHub Pages**, **Vercel**, or **Netlify**.
- **GitHub Pages**: Go to *Repository Settings* → *Pages* → Select `main` branch → *Save*.
